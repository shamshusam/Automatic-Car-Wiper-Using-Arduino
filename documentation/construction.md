# 🛠️ Construction Procedure

This section describes the step-by-step construction and assembly procedure for the reference Automatic Car Wiper Using Arduino system.

---

## 🔧 Step 1 — Prepare the Components

Collect the required components:

- Arduino Uno
- Rain sensor module
- SG90 servo motor
- Breadboard
- Jumper wires
- Wiper arm / mechanical linkage
- USB cable

---

## 🔌 Step 2 — Place the Components

Place the Arduino Uno and breadboard on a stable working surface.

Position the rain sensor where water can reach its sensing plate during testing.

The servo motor should be positioned so that its rotating horn can operate the wiper mechanism.

---

## 🌧️ Step 3 — Connect the Rain Sensor

Connect the rain sensor module to the Arduino Uno:

```text
Rain Sensor VCC → Arduino 5V
Rain Sensor GND → Arduino GND
Rain Sensor AO  → Arduino A0
